# Changelog
All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [1.1.0] - 2026-2-16
### Added
- Alert if no chapter titles would be uploaded due to the offset
- Video ID and chapter titles are required to enable the upload button
- Release notes are now properly rendered as markdown

### Fixed
- Fixed bug causing the auto-updater to throw an error when attempting to download the new version

## [1.0.0] - 2026-2-16
### Added
- Custom app icons for all platforms
- App is now "single instanced", so only one window will be open at a time
- Check for updates button and current version in settings

## [0.1.0] - 2026-2-16
### Added
- Initial release of Chapter Titler
- Support for both Windows and MacOS builds
